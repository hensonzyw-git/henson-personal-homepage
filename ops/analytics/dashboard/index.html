读数说明

读到一半：文章滚动达到 50%，且页面前台可见至少 30 秒。读到末尾：达到 90%，且前台可见至少 60 秒。这些是阅读信号，不等于确认读完或理解。

访客按 IP + 浏览器特征估算：共用网络可能少算，切换网络可能多算。没有访客 Cookie，也没有跨站身份。来源被浏览器隐藏时归入“直接 / 未知”。广告拦截、隐私设置或关闭 JavaScript 会造成少计。

这里仅展示埋点启用后的数据；历史 Nginx 日志另行查询，不混入行为统计。时区为上海，数据约每分钟汇总；页面会自动刷新。已过滤常见机器人，但不能保证所有上报都来自真人。

排除访问设置仅对本浏览器、此域名生效。看板本身不产生埋点。登录使用浏览器账号密码弹窗；建议使用自己的浏览器配置文件，关闭浏览器以结束凭据缓存。
